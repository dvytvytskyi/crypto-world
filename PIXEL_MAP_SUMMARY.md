## 🚀 Як використовувати

### 1. Відкрийте в браузері:
```
http://localhost:5000/pixel-map
```

### 2. Або через навігацію:
Натисніть **"Pixel Map"** в header сайту

## 🎮 Керування

| Дія | Як виконати |
|-----|-------------|
| Вибрати піксель | Клік лівою кнопкою |
| Масштабування | Колесо миші |
| Переміщення | Перетягування |
| Швидкий вибір | Shift + наведення |
| Зняти піксель | Клік на вибраний піксель |
| Очистити все | Кнопка "Очистити пікселі" |
| Змінити режим | Кнопка "Single/Grouped pixels" |
