# Pixel Map Page

## Опис
Інтерактивна сторінка для роботи з pixel map - картою світу, де можна вибирати окремі пікселі.

## Розташування
URL: `/pixel-map`

## Функціонал

### Основні можливості:
1. **Масштабування карти** - використовуйте колесо миші або жести для масштабування
2. **Переміщення карти** - перетягуйте карту для навігації
3. **Вибір пікселів** - клікайте на карту для вибору окремих пікселів
4. **Швидкий вибір** - утримуйте Shift і наводьте курсор для швидкого вибору
5. **Видалення пікселів** - клікніть на вже вибраний піксель для його видалення

### Режими роботи:
- **Single pixels** - вибір окремих пікселів
- **Grouped pixels** - вибір групових пікселів (тільки прямокутні області в одній країні)

## Технології
- **React** - UI фреймворк
- **D3.js** - для роботи з географічними даними та проекціями
- **Canvas API** - для рендерингу карти
- **SCSS** - для стилізації

## Як використовувати компонент

### Імпорт:
```javascript
import PixelMapPage from "./pages/PixelMapPage";
```

### Props для PixelMapCanvas:
- `selectedPixels` - масив вибраних пікселів
- `setSelectedPixels` - функція для оновлення вибраних пікселів
- `pixelsType` - тип вибору ("Single" або "Grouped")
- `setPixelsType` - функція для зміни типу вибору

### Формат даних пікселя:
```javascript
{
  x: number,           // координата X
  y: number,           // координата Y
  country: string,     // назва країни
  countryID: string    // ID країни
}
```

## Налаштування

### Параметри масштабування:
- Мінімальний зум: 1x
- Максимальний зум: 150x
- Сітка з'являється при зумі > 10x (desktop) або > 30x (mobile)

### Розміри canvas:
- Ширина: 1024px
- Висота: 650px
- Responsive: масштабується на менших екранах
