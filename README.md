# cryptoworld-fe


1) Диструктуризация страниц, каждая секция в отдельный компонент
2) Камл кейс для названий, кроме компонентов
3) Максимально переиспользываемость стилей, использывать модификаторы
4) Копоненты в папке должны называться index.jsx
5) Выносить в компоненты(папка components), если компонент встречается на других страницах
6) Выносить картиники в нужную папку, если встричаеться на нескольких стр. то в папку Global, если относиться к компоненту то в папку components
7) CEO - для картинок ( писать в теге - alt width height), h1-h6
8) Семантическая верстка
9) Использывать миксины
