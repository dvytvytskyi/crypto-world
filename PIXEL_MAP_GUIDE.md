# 🗺️ Гайд по Pixel Map

## Швидкий старт

Pixel Map тепер доступна як окрема сторінка за адресою: **`/pixel-map`**

## 🚀 Як запустити

1. Переконайтеся, що dev-сервер запущений:
```bash
yarn dev
```

2. Відкрийте в браузері:
```
http://localhost:5000/pixel-map
```

## 🎮 Керування

### Базові дії:
- **Клік лівою кнопкою миші** - вибрати/зняти піксель
- **Колесо миші** - масштабування карти (zoom)
- **Перетягування** - переміщення по карті
- **Shift + наведення курсора** - швидкий вибір пікселів

### Кнопки:
- **Single/Grouped pixels** - переключення режиму вибору
- **Очистити пікселі** - видалення всіх вибраних пікселів

## 📐 Режими роботи

### Single Pixels (Одиночні пікселі)
- Можна вибирати будь-які пікселі незалежно один від одного
- Немає обмежень на форму або розташування
- Підходить для точкового вибору

### Grouped Pixels (Групові пікселі)
- Пікселі мають формувати прямокутну область
- Всі пікселі повинні бути в одній країні
- Мінімум 4 пікселі для валідної групи
- Якщо область не валідна, з'явиться попередження

## 🎨 Візуальні індикатори

### Кольори на карті:
- **Фіолетовий (#A255FB)** - базова карта
- **Темно-фіолетовий (#6d39a8)** - вибрані пікселі
- **Сірий** - зайняті пікселі (недоступні)
- **Темно-синій (#6924B9)** - підсвітка під курсором

### Сітка:
- З'являється при зумі > 10x (desktop)
- З'являється при зумі > 30x (mobile)
- Допомагає точно вибирати пікселі

## 📊 Статистика

Під картою відображається:
- Кількість вибраних пікселів
- Поточний режим роботи

## 🛠️ Для розробників

### Структура компонентів:
```
PixelMapPage/
├── index.jsx              # Головна сторінка
├── Sections/
│   └── PixelMapCanvas/    # Canvas з картою
└── utils/
    └── pixelMapUtils.js   # Утиліти для роботи з пікселями
```

### Використання утиліт:
```javascript
import {
  getPixelsByCountry,
  exportPixelsToJSON,
  importPixelsFromJSON,
  getPixelsBounds,
  findPixelGroups
} from './utils/pixelMapUtils';

// Експорт пікселів
const jsonData = exportPixelsToJSON(selectedPixels);

// Імпорт пікселів
const pixels = importPixelsFromJSON(jsonString);

// Статистика по країнах
const stats = getPixelsByCountry(selectedPixels);

// Знайти групи пікселів
const groups = findPixelGroups(selectedPixels);
```

### Формат даних:
```javascript
const pixel = {
  x: 512,                    // координата X на canvas
  y: 325,                    // координата Y на canvas
  country: "Ukraine",        // назва країни
  countryID: "UA"           // код країни
};
```

## 🔧 Налаштування

Основні параметри в `PixelMapCanvas/index.jsx`:

```javascript
// Розміри canvas
width: 1024
height: 650

// Діапазон зуму
scaleExtent: [1, 150]

// Розмір пікселя
pixelSize: 1
```

## 🐛 Відомі обмеження

1. На мобільних пристроях сітка з'являється пізніше (zoom > 30x)
2. Grouped mode працює тільки з прямокутними областями
3. Максимальний зум обмежений 150x

## 💡 Поради

1. Починайте з малого зуму для загального огляду
2. Збільшуйте масштаб для точного вибору
3. Використовуйте Shift для швидкого вибору на desktop
4. В Grouped режимі вибирайте прямокутні області
5. Натискайте на вибрані пікселі для їх видалення

## 📞 Підтримка

Якщо виникли проблеми:
1. Перевірте консоль браузера на помилки
2. Спробуйте оновити сторінку
3. Очистіть кеш браузера
4. Переконайтеся, що всі залежності встановлені (`yarn install`)
